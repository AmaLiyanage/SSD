# SE4030 – Secure Software Development Assignment

## Project Title

**Water Well Condition Management System – WELLSYNC**

This project was developed as part of the **SE4030 – Secure Software Development** group assignment. The purpose of this assignment is to identify security vulnerabilities in an existing web application, analyze their impact, implement appropriate fixes, and enhance the application with an OAuth-based authentication feature.
